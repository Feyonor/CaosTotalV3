# 🌍 DIMENSIÓN DEL CAOS - Guía Completa

## 📋 Descripción

La **Dimensión del Caos** es un mundo alternativo dentro de Caos Total V3 diseñado para crear el máximo caos con tus amigos.

## 🎮 Cómo acceder

### Paso 1: Construir el Portal
```
███████
█     █
█     █  (Bloques de Diamante en patrón 3x3)
█     █
███████
```

### Paso 2: Craftear el Mechero del Caos
```
Receta:
🔨 Flint and Steel + Redstone Block = Chaos Lighter
```

### Paso 3: Activar el Portal
- Sostén el **Chaos Lighter** en la mano
- Haz click derecho en los bloques de diamante
- ¡Teleportado a la Dimensión del Caos!

## 🌎 Características de la Dimensión

### Terreno
- **Base (0-60 bloques)**: Obsidiana sólida
- **Capa Media (60-80 bloques)**: Diamantes y Obsidiana
- **Plataformas (80-120 bloques)**: Netherita flotante
- **Cielo (120-140 bloques)**: TNT y Redstone flotantes

### Biomas
- Paisaje completamente caótico
- Sin criaturas pasivas
- Mobs enemigos potenciados
- Poca visibilidad de noche

## 💥 Items del Caos

| Item | Craft | Efecto |
|------|-------|--------|
| **Chaos Grenade** | TNT + Redstone + Diamante | Explosión potente |
| **Rocket Launcher** | Hierro + Redstone + TNT | Dispara cohetes |
| **Bazooka** | Hierro + Diamante + TNT | Máximo daño |
| **Surprise Box** | Redstone + Hierro + Cofre | Items aleatorios |
| **Chaos Lighter** | Flint & Steel + Redstone Block | Activa portales |

## 📊 Estadísticas del Jugador

- **Vida Máxima**: 1000 HP (50 corazones)
- **Contador de Muertes**: Visible en el servidor
- **Sin ventajas especiales**: Todos iguales

## ⚡ Comandos

### Comandos Normales
```
/home set <nombre>          - Guardar ubicación
/home <nombre>              - Ir al home
/home list                  - Ver tus homes
/home delete <nombre>       - Eliminar home
```

### Comandos Admin (Nivel 2+)
```
/caosadmin tntrain          - Lluvia de TNT
/caosadmin invade           - Invasión de mobs
/caosadmin meteorite        - Meteoritos
/caosadmin summonking       - Invocar Rey Creeper
```

## 🎯 Estrategias de Juego

### Offensiva
1. Mina diamantes en las plataformas
2. Craftea armas caóticas
3. Busca sorpresas en Cajas Sorpresa
4. Ataca a otros jugadores

### Defensiva
1. Construye bases en las plataformas
2. Guarda armadura antiexplosiones
3. Establece varios homes para escapar
4. Mantén distancia del Rey Creeper
